Файл содержит 34 проверки, включая кеш, бюджет запросов, квоты, задержки повторов, JSON Schema, неверные ответы и отсутствие утечки ключа.

Чтобы воспроизвести выбранные проверки, клонируйте отборочный репозиторий, перейдите на коммит `e2f4877`, установите его зависимости и выполните `python -m pytest tests/test_llm.py -q`. Наш повтор использовал Python 3.12.14 и зависимости, перечисленные в `requirements.lock.txt` нового проекта.
